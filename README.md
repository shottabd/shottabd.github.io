# সত্তা (Shotta)

মানসিক স্বাস্থ্য ও প্রশিক্ষণ কেন্দ্র, ঢাকা। এই রিপোজিটরিতে সত্তার ওয়েবসাইটের দেখানোর সংস্করণ রাখা আছে।

- ওয়েবসাইট: https://shottabd.github.io
- ফোন ও WhatsApp: 01788-116045

## এখানে কী আছে

`site.zip` ফাইলে পুরো সাইট (বাংলা ও ইংরেজি) রাখা আছে। প্রতিবার এই ফাইল বদলালে GitHub নিজেই সাইটটা নতুন করে চালু করে দেয় (`.github/workflows/deploy.yml`)।

এই সংস্করণে লেখা, অভিধান, সেলফ-টেস্ট, খোঁজা, বইয়ের নমুনা পাতা আর কার্ট সবই কাজ করে। শুধু ফর্মগুলো কোনো সার্ভারে জমা হয় না; জমা দিলে লেখা তথ্যসহ WhatsApp মেসেজ তৈরি হয়, অথবা সরাসরি ফোন করা যায়।

আসল সাইট চলবে ওয়ার্ডপ্রেসে, সত্তার নিজস্ব থিম আর প্লাগইন দিয়ে। সেখানে ফর্ম, বুকিং, অর্ডার আর রিভিউ সরাসরি অ্যাডমিন প্যানেলে জমা হয়।

---

**Shotta** is a mental health and training centre in Dhaka. This repository holds a preview of its website. Everything is in `site.zip`; the workflow in `.github/workflows/deploy.yml` publishes it to GitHub Pages whenever the file changes. Forms in this preview open WhatsApp with the details filled in instead of posting to a server. The live site runs on WordPress with Shotta's own theme and plugin.
